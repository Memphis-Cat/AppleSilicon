# P1.08 Fixtures

These files are synthetic QEMU MMIO trace records used only to validate P1.08 analysis behavior.

```text
reference.trace          canonical reference sequence
equivalent.trace         same guest semantics with different host noise
value-divergence.trace   one changed guest MMIO value
insertion.trace          one inserted event followed by resynchronization
```

No fixture contains real Apple firmware, macOS data, machine identifiers, credentials, or captured user data.
